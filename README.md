# PM Sentences Task (KS16)

Prospective memory sentences task built in PsychoPy.

## Attribution

Task files by Morys-Carter & Fredman Stein (2016), also described in Fredman Stein et al. (2018). Shared by the authors via the PsychoPy forum.

## License

No license was stated with the files. This repo is private until the authors confirm a license — check with them before sharing it publicly.

## Files

- `pm_sentences_ks16.psyexp` — the PsychoPy experiment (built in PsychoPy 1.83)
- `food.xlsx`, `vehicles.xlsx` — target sentence lists (food / vehicle cues)
- `fillers.xlsx`, `filler blocks uneven.xlsx` — filler sentences
- `food and vehicles cues.xlsx` — cue list

## Running it

Open `pm_sentences_ks16.psyexp` in PsychoPy Builder and run. Participant data saves to `data/`, which is git-ignored.
